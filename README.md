# 🧠 Svora Manager

Система управления студией звукозаписи: бронирование, работа с проектами, треками, версиями и комментариями.

---

## 🚀 Описание проекта

Svora Manager — это fullstack-приложение, которое решает задачи:

* 📅 бронирование студийного времени
* 🎵 управление музыкальными проектами (single / album)
* 🎚 работа с треками и версиями
* 💬 комментарии и фидбек по аудио
* 🔐 роли пользователей (client / owner)

---
## 🧠 Подход к разработке

Проект разрабатывается итеративно (в духе Agile-подхода):

- сначала реализуется базовый backend с ключевой бизнес-логикой
- затем строится минимальный рабочий frontend (основной пользовательский flow)
- после этого система расширяется:
  - добавляются новые endpoints
  - усложняется логика
  - улучшается UI

Такой подход позволяет:

- быстрее получить работающий продукт
- не переусложнять архитектуру на старте
- принимать решения на основе реального использования
- постепенно масштабировать систему

👉 Сначала реализуется “сквозной сценарий” (booking → project → track → comment), затем добавляются дополнительные возможности.
