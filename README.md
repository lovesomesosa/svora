# 🧠 AI Decision Helper

## 📌 Общая идея

**AI Decision Helper** — веб-приложение, которое помогает пользователю решать проблемы через итеративный диалог с AI и накопленную базу решений.

Особенности:  
- Каждая проблема у пользователя имеет **свой статус**: решена / не решена.  
- Пользователь может видеть **историю всех своих проблем** и решений.  
- Система позволяет:  
  - генерировать решения через AI  
  - показывать похожие кейсы из базы  
  - итеративно пробовать новые решения до успеха  
  - сохранять успешные решения

## 🔄 Основной процесс работы

### 1. Создание проблемы
- Пользователь вводит описание проблемы  
- Создаётся **сессия `Problem`**  
- Проблема **по умолчанию считается нерешённой**  

### 2. Генерация решения
- Система (AI + поиск по базе) создаёт `Solution`  
- Пользователю показывается решение и, опционально, похожие кейсы  

### 3. Обратная связь
- Система спрашивает: “Помогло ли это решение?”  

### 4. Поведение при “не помогло”
Пользователь может:  
1. Просто нажать “не помогло” → система генерирует новое решение  
2. Дать уточнение → AI учитывает новый контекст и генерирует более точное решение  
3. Не давать уточнения → AI решает, нужно ли уточнить или сразу дать следующее решение  

### 5. Завершение
- Пользователь отмечает успешное решение  
- Проблема помечается как **решённая**  
- Несколько решений могут быть успешными  
- Сессия сохраняется в истории пользователя

## 🧱 Структура данных

### 1. User
```ts
User {
  id
  name
  email
  passwordHash
}
```
### 2. Problem
```ts
Problem {
  id
  userId //владелец проблемы
  initialText //описание проблемы
  status // 'solved' | 'unsolved'
  createdAt
  solvedAt // дата решения/null
}
```
### 3. Message
```ts
Message {
  id
  problemId
  role // 'user' | 'assistant'
  type // 'problem' | 'solution' | 'feedback' | 'message'
  text
  createdAt
}
```
### 4. Solution
```ts
Solution {
  id
  problemId
  messageId
  isSuccessful
  source
}
```

## 🔗 Связь данных

- Один пользователь → множество проблем
- Одна проблема → множество сообщений
- Одна проблема → множество решений
- Решения могут быть отмечены как успешные
- Статус проблемы = «решена», если хотя бы одно решение успешно

## 🖥️ Интерфейс

### Главная страница
- Список проблем пользователя
- Каждая проблема показывает:
    - текст
    - статус (решена / не решена)
    - дата создания и, если решена, дата решения
### Экран диалога
- Сообщения пользователя и AI
- Решения
- Кнопки:
    - текст
    - статус (решена / не решена)
    - дата создания и, если решена, дата решения
### Дополнительно
- История успешных решений
- Похожие кейсы и рекомендации
- Фильтры по тегам / категориям

## ⚙️ Технологический стек
- Frontend: React / Next.js
- Backend: Node.js / Express.js
- База данных: PostgreSQL (опционально с pgvector для embeddings)
- AI: интеграция через API (например OpenAI)
- Документация API: Swagger / OpenAPI
- Version control: Git + GitHub
- CI/CD: GitHub Actions (тесты, линтинг, билд, деплой)
- Docker: контейнеризация backend + БД
