## 3️⃣ Реализация базового API (Express + TypeScript)

### Auth
- [ ] `POST /auth/register`  
- [ ] `POST /auth/login` (JWT)

### Booking
- [ ] `GET /bookings/available` — свободные слоты  
- [ ] `POST /bookings` — создание брони  
- [ ] `GET /bookings` — список броней пользователя  
- [ ] `GET /bookings/all` — все брони (только для owner)  
- [ ] `PATCH /bookings/:id/status` — подтверждение/отмена (owner)

### Projects & Tracks
- [ ] `POST /projects` — создание проекта (single/album)  
- [ ] `GET /projects` — проекты пользователя  
- [ ] `GET /projects/:id` — детальная информация о проекте  
- [ ] `POST /projects/:id/tracks` — добавление трека  
- [ ] `POST /tracks/:id/versions` — загрузка новой версии (ссылка на файл)  
- [ ] `POST /tracks/:id/comments` — добавление комментария

## ⚡ Итог MVP

После выполнения основного плана пользователь сможет:

- Зарегистрироваться как клиент или owner  
- Бронировать студию онлайн  
- Создавать и управлять музыкальными проектами (single / album)  
- Загружать треки и их версии  
- Оставлять комментарии с таймкодами  
- Владельцы смогут управлять всеми бронями и видеть полную картину  

> Дальше проект легко масштабируется до полноценной SaaS-платформы для студий звукозаписи.
